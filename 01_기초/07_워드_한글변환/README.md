# 기초 7강 — 워드 ↔ 한글(HWP) 변환 (워드에서 HWP 가 안 열릴 때, 한글에서 DOCX 로 저장, 바뀌는 것)

- 강의: https://www.coding-now.com/blog/word/word-basic-07-hwp-conversion
- English: https://www.coding-now.com/en/blog/word/word-basic-07-hwp-conversion

## 파일

| 파일 | 내용 |
|---|---|
| `실습.docx` | 워드로 만든 가상 '사진 동아리 12월 모임 안내' 3쪽 — 맑은 고딕(제목 16pt 굵게 · 소제목 13pt · 본문 11pt), 표 3×3, 그림 하나, 바닥글 쪽 번호(PAGE 필드) |
| `실습.hwp` | 같은 내용을 한글 2024 로 만든 것 2쪽 — 함초롬바탕(본문 10pt) · 줄 간격 160%, 표 3×3, 그림 하나, 쪽 번호 매기기(가운데 아래 '- 1 -') |
| `정답.hwp` | `실습.docx` 를 한글 2024 로 열어 HWP 로 저장한 것 |
| `정답.docx` | `실습.hwp` 를 한글 2024 다른 이름으로 저장 → 형식 OOXML(.docx) 로 저장한 것 |
| `practice.*` · `answer.*` | 영어판 강의용 같은 연습 파일(영어 글) |
| `measure.py` → `measure.json` | 양쪽에서 만든 문서를 서로 바꾸고 다시 열어 쪽 수 · 글꼴 · 글자 크기 · 줄 간격 · 표 · 그림 · 쪽 번호 · 여백을 잰 값, 워드 파일 변환기 목록, 워드로 .hwp · .hwpx 직접 열기 결과 |
| `measure.py en` → `measure_en.json` | 영어판 자료로 같은 측정 |
| `make_files.py` | 실습 · 정답 파일 가져오기(먼저 measure.py) — DOCX 작성자(core.xml) · HWP 문서 정보 작성자를 CODINGNOW 로 |
| `hwp_author.py` | HWP 문서 요약 정보의 작성자 · 마지막 저장한 사람을 CODINGNOW 로(한글이 저장 때 윈도 계정 이름을 넣음 — 윈도 구조화 저장소 API 로 요약 정보 스트림만 다시 씀) |
| `screens.py` · `crop_web.py` | 강의 화면(`shots/`, 저장소에는 올리지 않음) — 워드 [파일 변환] 창, .hwp 를 그냥 연 화면, 아래아 한글 97 변환기 오류, 한글이 만든 DOCX 를 워드로 연 화면, 한글 '호환 문서' 창 |

스크립트는 Windows + 워드 + 한글 2024 + `pip install pywin32 pymupdf pillow` 에서 돈다. 워드 · 한글을 자동화로 띄우고(창 숨김) 문서는 %TEMP% 에 저장한다
(한글은 %TEMP% 밖에 저장하면 '파일 접근 허용' 창이 뜬다). 한글이 HWP 가 아닌 형식으로 저장할 때 뜨는 '호환 문서' 창은 감시 스레드가 [계속] 으로 넘긴다.
이 PC 한글 2024 는 구독이 없어 편집 창이 열리지 않고 HAction.Run 편집 동작이 False 지만, InsertText · TableCreate · CharShape · PageNumPos 의 HAction.Execute, 표 칸 이동(SetPos 목록 번호), InsertPicture 는 된다.

## 핵심 (11/11, 워드 16.0.20527 · 한글 2024 13.0.0.4132)

- 워드 파일 변환기: '아래아 한글 2.0-97'(HWP, 열기 · 저장) · '아래아 한글 2.1/2.5'(저장만) — 요즘 HWP(한글 2024 저장)를 여는 변환기는 없다.
- 워드로 실습.hwp 를 그냥 열면: 오류 없이 알아볼 수 없는 글자로 열림(383쪽 · 57,533자, 글꼴 굴림체). 변환 확인을 켜면 [파일 변환] 창 — 워드가 '인코딩된 텍스트'를 골라 둠.
  '아래아 한글 2.0-97' 변환기로 열게 하면 '아래아 한글 2.0-97 형식이 아닙니다.' → '파일을 열 수 없습니다.' · .hwpx 는 '파일이 손상되었습니다.'
- 한글 2024 는 DOCX 를 바로 연다(3쪽 그대로). HWP 로 저장하면 맑은 고딕 · 글자 크기 16/13/11 · 굵게 · 표 3×3 · 그림 유지, 줄 간격은 워드 '1줄' → 한글 100%, 워드 바닥글 쪽 번호 → 한글 꼬리말 쪽 번호(PDF 아래 1 · 2 · 3).
- 한글 → DOCX 는 다른 이름으로 저장 형식 OOXML(자동화 형식 이름 'OOXML', 'DOCX' 는 False). 저장 때 '호환 문서 — 이 파일을 저장하면 문서 내용의 배치가 변경될 수 있습니다.' 창.
  워드로 열면: 2쪽 → 3쪽, 함초롬바탕 · 10pt · 표 · 그림 유지, 줄 간격 160% → '배수 1.6'(19.2pt), 여백 35/30/30/30mm 그대로, **쪽 번호 사라짐**(바닥글 없음), 제목 표시줄 '호환성 모드'(CompatibilityMode 12).
- 함초롬바탕이 없는 PC 에서 이 DOCX 가 어떻게 보이는지는 이 PC(한글 설치됨)에서 확인 안 됨.
