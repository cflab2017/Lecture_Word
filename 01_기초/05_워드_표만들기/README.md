# 기초 5강 — 워드 표 만들기 (표 삽입, 텍스트를 표로 변환, 머리글 행 반복, 자동 맞춤)

- 강의: https://www.coding-now.com/blog/word/word-basic-05-make-table
- English: https://www.coding-now.com/en/blog/word/word-basic-05-make-table

## 파일

| 파일 | 내용 |
|---|---|
| `실습.docx` | 따라 할 파일 — 가상 독서 모임 명단 45명(번호 · 이름 · 연락처, 전화번호는 010-0000-xxxx 꼴 가짜)을 탭으로 나눈 글, 2쪽 |
| `정답.docx` | 같은 명단을 텍스트를 표로 변환(탭) → '표 구분선' · 첫 행 페이지마다 머리글 행 반복 · 내용에 자동으로 맞춤 |
| `practice.docx` · `answer.docx` | 영어판 강의용 같은 연습 파일 |
| `measure.py` → `measure.json` | 강의에 적은 값을 워드로 다시 재는 스크립트 — 표 삽입 기본(스타일 · 열 너비), 탭 · 쉼표 변환, 46행 표 머리글 반복 끔/켬(PDF 쪽별), 자동 맞춤 너비, 표 분할, 메뉴 글자 |
| `measure.py en` → `measure_en.json` | 영어판 자료로 같은 측정 |
| `make_files.py` | 실습 · 정답 파일 만들기(`en` 이면 영어판) |
| `screens.py` → `crop_web.py` | 강의 화면(`shots/`, 저장소에는 올리지 않음) — 탭 표시 · 텍스트를 표로 변환 창 · 정답 2쪽 · 표 속성 행 탭 · 쉼표 함정 |

스크립트는 Windows + 워드 + `pip install pywin32 pillow pymupdf` 에서 돈다. 워드를 따로 띄워 쓰고, 시험 문서는 저장하지 않고 닫는다. 작성자 정보는 저장 뒤 CODINGNOW 로 바꿨다.

## 핵심

- 화면처럼 넣은 4열 표(Tables.Add 4번째 인자 1): '표 구분선', 112.7pt × 4 = 본문 폭 451.3pt. COM 기본(0)은 '표준 표'(테두리 없음).
- 탭으로 나눈 4줄 → 4행 3열. '서울, 강남,2' 를 쉼표로 변환 → 서울 · 강남 · 2 세 칸.
- 46행 표(2쪽): 머리글 반복 끔 → 머리글 글자가 PDF 1쪽에만, 켬 → 1 · 2쪽. 2행만 켜도 1행이 같이 켜짐.
- 내용에 자동으로 맞춤: 150.2 × 3 → 32.8 · 43.8 · 86.5pt(합 163.1, 영어판 25.9 · 40.5 · 86.5 = 152.9). 새 표(고정 너비)에 COM 으로 바로 내용 맞춤을 하면 안 바뀌어 창 맞춤 → 내용 맞춤 순서로 쟀다.
- 문서 맨 위 표 첫 칸에서 표 분할 → 표 앞 단락 1.
